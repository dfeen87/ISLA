# BEDROCK 1.0 Invariant Register

This document tracks the verified guarantees of the Phased-Music-Notes engine.

## DSP Invariants

1. **Identity Transform (HarmonicBlender)**
   * **Invariant**: `HarmonicBlender(strength=0.0)` must output a bitwise/numerically equivalent signal to the input (within standard 32-bit float epsilon bounds), for any sample rate, stream configuration, and window length (even or odd).
   * **Test**: `test_harmonic_blender_identity`, `test_harmonic_blender_matrix`, `test_harmonic_blender_odd_windows`
   * **Status**: Verified

2. **Phase Continuity in Harmonic Content**
   * **Invariant**: High-energy frequency bins containing prominent harmonic data must largely retain their phase angle to prevent transient smearing and phase cancellation.
   * **Test**: `test_harmonic_blender_mono`, `test_harmonic_blender_stereo`
   * **Status**: Verified

3. **Mono/Stereo Output Length Preservation**
   * **Invariant**: The exact sample length and dimensionality passed to `blend()` must be returned unmodified, regardless of internal window sizes or frame boundaries.
   * **Test**: `test_harmonic_blender_handles_empty_and_short_audio`
   * **Status**: Verified

4. **Empty and Short Audio Handling**
   * **Invariant**: Processing 0-length arrays returns an empty array. Processing arrays shorter than one window length returns arrays padded and truncated exactly to their original shape without throwing index bounds exceptions.
   * **Test**: `test_harmonic_blender_handles_empty_and_short_audio`, `test_short_framing_and_general_overlap_add_shape`
   * **Status**: Verified

5. **Stereo Buffer Semantics**
   * **Invariant**: All stereo arrays must strictly adhere to the shape `(numSamples, 2)`.
   * **Test**: `test_harmonic_blender_stereo`, `test_mono_stereo_conversion`
   * **Status**: Verified

## Streaming & Service Invariants

1. **HTTP/gRPC Dimensional Safety**
   * **Invariant**: External requests via HTTP and gRPC handle mono/stereo automatically and output audio shapes match what is generated by the engine.
   * **Test**: `test_grpc_smooth_block_mono`, `test_smooth_endpoint`
   * **Status**: Verified

2. **Python Bridge Initialization Safety**
   * **Invariant**: Consecutive calls to `init_python` or repeated process blocks do not corrupt global state.
   * **Test**: `test_bridge_init`, `test_bridge_process_mono`
   * **Status**: Verified
