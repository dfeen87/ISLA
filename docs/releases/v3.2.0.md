# ISLA v3.2.0 — Audio Control Center

**Release scope and provenance · 24 October 2026**

ISLA v3.2.0 introduces an optional, clickable desktop **Audio Control Center** for local-file ALIVE playback and guided macOS LIVE system-audio monitoring, while retaining the terminal and offline export workflows. The version also includes the accumulated research-preservation and CI work merged since [v3.1.1](https://github.com/dfeen87/ISLA/releases/tag/v3.1.1).

This is the source release note. A GitHub release and tag are **separate publication actions**; their existence must be verified independently. The package version alone is not proof that a GitHub release has been published.

## Desktop control window — merged PR #34

- Launch an optional Qt Widgets interface with `isla window`, `python -m isla window`, or `window` from the existing `isla>` prompt.
- Preserve bare `isla`, `python -m isla` and the existing `--input/--output/--mode` offline CLI.
- ALIVE: WAV picker, preparation progress, playback controls, Velvet/Legato/Melt and original Bypass, playback position, and guarded selections.
- LIVE: BlackHole 2ch capture, verified physical stereo output selection, 44.1/48 kHz rates, routing-readiness checks, Sound Settings guidance, start/stop, mode selection and health feedback.
- Share the existing terminal controller and audio-engine ownership; no second DSP path and no unsafe Mac default-device writes.
- Qt dependency remains optional: `python -m pip install -e '.[gui]'`. CLI-only installation continues to work without Qt.
- See [Control Center acceptance and mapping](../control-center/ACCEPTANCE.md) and the [README GUI walkthrough](../../README.md#isla-control-center--graphical-interface).

## Installation and launch

From a Python 3.10+ checkout:

```bash
python -m pip install -e '.[gui]'
python -m isla window
# Or from an active environment:
isla window
```

ALIVE can process local WAV without BlackHole. LIVE requires macOS 13+, installed standalone BlackHole 2ch, a distinct physical stereo output and manual macOS Sound > Output selection of BlackHole 2ch. ISLA does not modify the macOS default output. Restore it manually after LIVE.

## Validation evidence and limitations

PR #34 reports a complete local GUI-enabled test run (**477 passed, 1 existing expected failure**) on a Linux host, plus offscreen Qt interaction and CLI compatibility tests. A clean no-Qt installation was separately exercised. These are reported implementation observations, not proof of physical native Mac success. CI evidence for the exact proposed release commit must be verified before publication.

**Physical macOS GUI/audio acceptance remains pending**, including real BlackHole routing, device hot-plug, live listening, recovery over longer sessions and Bluetooth hardware. Hosted offscreen macOS tests are not equivalent to audio-device or user-interaction acceptance. LIVE remains experimental; no professional real-time guarantee, Windows LIVE implementation, standalone macOS installer, or production v4.0 remastered DSP is claimed.
